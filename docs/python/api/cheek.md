# Cheek landmarks

For what the cheek landmarks are and how they're found, see [Cheek measures](../../measures.md#cheek-measures) in the measures catalog and the [landmarks guide](../../guide/landmarks.md#cheek-landmarks). The measures that report them are on the [Measures](measures.md) page: [`AnalyzeLandmarks`][dynaface.measures_frontal.AnalyzeLandmarks], whose "Cheek Landmarks" item holds their coordinates, and [`AnalyzeCheekMeasures`][dynaface.measures_cheek.AnalyzeCheekMeasures], which reports the numbers about them.
